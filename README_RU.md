# NightDim — затемнение экрана Windows ниже минимальной яркости

**NightDim** — бесплатная программа с открытым исходным кодом для **Windows 10 и 11**. Она позволяет сделать экран ноутбука или монитора **темнее минимального уровня яркости**, доступного в настройках Windows. Особенно удобно ночью.

**Языки инструкции:** [English](README.md) · [Русский](README_RU.md) · [Српски (ћирилица)](README_RS.md)

> **Установщик в одном EXE.** В релизе находится `NightDimSetup.exe`, который устанавливает NightDim в выбранную папку. Интерфейс доступен на **английском, русском и сербском (кириллица)**.

## Скачать и установить

1. Откройте [последний релиз на GitHub](../../releases/latest).
2. В разделе **Assets** скачайте **`NightDimSetup.exe`** (не архивы **Source code**).
3. Запустите мастер установки, примите лицензионное соглашение, выберите папку (по умолчанию `Program Files (x86)\TheITDaily\NightDim`), настройте галочки **автозапуска** и **ярлыка в меню «Пуск»**, затем нажмите **«Установить»** и **«Готово»**.
4. На последнем шаге оставьте галочку **«Запустить NightDim сейчас»**, чтобы программа открылась после нажатия «Готово». Либо запустите её позднее через меню «Пуск».

Windows может запросить права администратора **при установке или удалении файлов из защищённой папки**. Автозапуск и ярлык относятся к текущему пользователю Windows. Требуются Windows 10/11 и .NET Framework 4.x. Портативный `NightDim.exe` по-прежнему можно собрать из исходников.

## Возможности

- **Затемнение от 0 до 95%** поверх обычной яркости Windows.
- **30 секунд на подтверждение** только при усилении затемнения. Окно появляется примерно через **0,7 секунды после отпускания ползунка**, а не во время перетаскивания. Без подтверждения настройки откатятся.
- **Расписание:** по умолчанию затемнение **выключено с 08:00 до 20:00**. Время можно изменить, а расписание — отключить.
- **Три языка интерфейса:** английский, русский и сербский (кириллица). Выбор сохраняется сразу и не требует подтверждения затемнения.
- **Интеграция с Windows:** автозапуск для текущего пользователя и ярлык в меню «Пуск». Оба параметра доступны и в настройках самой программы. При автозапуске приложение сворачивается в трей.
- **Проверка обновлений:** кнопка **«Проверить обновления»** сравнивает установленную версию с последним опубликованным GitHub Releases. При наличии новой версии предлагает открыть страницу загрузки. Автоматического скачивания и запуска нет.
- **Работа в трее** рядом с часами Windows.
- **Несколько мониторов** и горячие клавиши.
- **Экспериментальное затемнение указателя мыши** через гамма-коррекцию видеокарты (работает не на всех устройствах).

## Как пользоваться

1. В верхней части окна в меню **«Язык»** выберите **English**, **Русский** или **Српски (ћирилица)**. Выбор сохранится автоматически.
2. Передвиньте ползунок затемнения и отпустите его. **Если экран стал темнее**, примерно через **0,7 секунды** появится окно подтверждения. **30 секунд** отсчитываются от последнего изменения. Если экран стал светлее или его видимая яркость не изменилась (например, во время паузы по расписанию), подтверждение не требуется.
3. Когда появится запрос, нажмите **«Принять»** в течение 30 секунд или **«Вернуть (Esc)»**, чтобы отменить изменение. Без подтверждения восстановятся предыдущие подтверждённые настройки. Окно подтверждения специально остаётся светлым.
4. Чтобы настроить дневной перерыв, включите флажок **«Не затемнять по расписанию»** и выберите время начала и окончания (по умолчанию **08:00–20:00**). Снимите флажок, если расписание не нужно.
5. Закройте окно настроек, чтобы скрыть программу в трей. Значок рядом с часами позволяет вернуть окно или выйти; кнопка **«Выход»** полностью закрывает NightDim.

6. В настройках можно в любой момент изменить галочки **«Запускать вместе с Windows»** и **«Добавить ярлык в меню «Пуск»»**. На затемнение эти параметры не влияют.
7. Нажмите **«Проверить обновления»**, чтобы проверить GitHub Releases (нужен интернет).

При активном затемнении покрываются и обычные окна, и сама программа, и панель задач с треем. **Исключение — светлое окно подтверждения**, необходимое для безопасности. Курсор можно попытаться затемнить отдельно, но это экспериментальная функция.

### Если экран стал слишком тёмным

| Клавиши | Действие |
| --- | --- |
| `Ctrl + Alt + ↓` | Затемнить ещё на 5% (потребуется подтверждение) |
| `Ctrl + Alt + ↑` | Осветлить на 5% (новое подтверждение не требуется) |
| `Ctrl + Alt + F12` | Сразу отключить затемнение до следующего запуска |
| `Esc` в окне подтверждения | Отменить изменение |

Нажмите **`Ctrl + Alt + F12`**. Если сочетание занято, откройте **командную строку** в папке программы и выполните **`NightDim.exe --stop`**: приложение корректно завершит работу. Не закрывайте его через `taskkill /F`.

## Важные ограничения

- Программа уменьшает **видимую яркость программно**, а не физическую яркость подсветки. Экономия энергии подсветки не гарантируется.
- Нельзя гарантировать затемнение *абсолютно всего*: экран входа Windows, защищённые запросы UAC, некоторые полноэкранные игры, HDR и защищённое видео могут не затемняться.
- **Затемнение курсора экспериментальное.** Гамма-коррекция может конфликтовать с HDR, ночным светом, ICC-профилями и программами калибровки цветов. При искажениях отключите эту опцию и выйдите из NightDim обычным способом, чтобы программа попыталась восстановить цвета. Не завершайте процесс принудительно.
- Горячие клавиши могут не сработать, если они заняты другим приложением.
- Установщик и программа пока **не подписаны цифровой подписью**. Windows SmartScreen или антивирус могут предупреждать о запуске. Скачивайте файлы только из Releases этого репозитория.

Подтверждённые настройки хранятся в `%APPDATA%\NightDim\settings.txt`. Чтобы вернуть всё по умолчанию, закройте NightDim и удалите этот файл.

## Сборка из исходников

Нужны Windows и компилятор C# из **.NET Framework 4.x** (`csc.exe`). В одной папке должны лежать `NightDim.ico`, `NightDim.cs`, `ReleaseChecker.cs`, `NightDim.Setup.cs`, `WindowsIntegration.cs`, `UiText.cs` и `AssemblyInfo.cs`.

1. Скачайте исходники через **Code → Download ZIP** и распакуйте их.
2. Запустите **`Build_NightDim.bat`**, чтобы собрать портативный `NightDim.exe` в корне проекта.
3. Запустите **`Build_Release.bat`**, чтобы собрать программу и установщик. Для публикации на GitHub нужен файл `dist/<version>/NightDimSetup.exe`.

Мастер покажет [пользовательское соглашение и лицензию MIT](EULA.txt) с отказом от гарантий и ограничением ответственности. Соглашение и лицензия сохраняются в папке программы (`EULA.txt` и `LICENSE.txt`). Действие таких условий зависит от применимого законодательства.

## Обновление и переустановка

Скачайте новый `NightDimSetup.exe` из GitHub Releases и запустите поверх установленной версии. Мастер определит старую версию, выберет прежнюю папку и корректно завершит запущенный NightDim перед заменой файлов. Пользовательские настройки, автозапуск и ярлык сохраняются. На последнем шаге можно запустить программу. Повторный запуск установщика той же версии выполняет переустановку; установка более старой версии поверх новой запрещена. Если нужна другая папка, сначала удалите программу.

Проверка обновлений только показывает новую версию и открывает GitHub: программа ничего не скачивает и не устанавливает автоматически. Для уведомления в GitHub должен быть опубликован релиз с более новым номером версии.

## Удаление программы

Откройте **Параметры Windows → Приложения → Установленные приложения** (Windows 11) или **Приложения и возможности** (Windows 10), найдите **NightDim** и выберите **«Удалить»**. Также можно запустить `uninstall.exe` из папки установленной программы.

Деинсталлятор корректно завершит NightDim и удалит файлы приложения, автозапуск, ярлык меню «Пуск» и запись из списка установленных приложений. При удалении из **Program Files (x86)** Windows может запросить права администратора. Настройки в `%APPDATA%\NightDim\settings.txt` **сохраняются**, чтобы их можно было использовать при переустановке. Посторонние файлы в папке программы не удаляются.

Портативный `NightDim.exe`, запущенный без установщика, в списке установленных приложений не появляется.
